# @hlw-ele/mp-wx

`@hlw-ele/mp-wx` 是针对微信小程序的构建与上传工具库，基于微信官方 `miniprogram-ci` 提供了小程序代码自动构建、版本修改与后台自动上传的集成逻辑。

## 安装

```bash
pnpm add @hlw-ele/mp-wx
```

## 功能特点

- **自动编译与上传**：封装了微信开发者工具命令行，支持静默启动编译和自动化上传。
- **自定义日志反馈**：格式化上传和编译过程中的输出信息，实时推送状态。
- **配置管理**：支持读取和应用特定的 AppID、版本号及上传描述。
